# 租屋守門人 RentGuard｜Demo

> NextWave AI 法創黑客松 2026 參賽作品原型
> 陪大學生走完租屋的 AI 助手：同一份租屋檔案，從簽約一路用到退租。

**線上 Demo**：https://tiffany950503-prog.github.io/rentguard-demo/

## 解決什麼問題

第一次租屋的大學生常在沒有人陪同下簽約，看不出押金三個月、禁止申請租金補貼、提前退租沒收全部押金這類條款是否合法；入住時沒拍照，退租時就難以舉證。問題的核心是**資訊不對稱與證據斷裂**。

## 四個功能

| 功能 | 何時用 | 做什麼 |
| --- | --- | --- |
| ① 契約紅綠燈 | 簽約前 | 逐條比對住宅租賃規定，用紅黃綠燈標出違法與不利條款，附條文出處，並產生可以傳給房東的協商訊息 |
| ② 點交存證 | 入住當天 | 依房型逐區檢查與拍照，產生帶時間戳記的點交清單，存進「租屋檔案」 |
| ③ 押金追回 | 退租後 | 把房東的扣款對應到入住紀錄，逐筆判斷能否爭取，產出協商訊息與後續行動 |
| ＋ 財稅試算 | 每年五月 | 試算房屋租金支出特別扣除額（每戶上限 18 萬元）、列出應備文件 |

## 快速體驗（1 分鐘）

1. 到「① 契約紅綠燈」按 **載入示範契約** → **開始掃描**，會看到 4 條紅燈、3 個黃燈。
2. 到「③ 押金追回」按 **載入示範扣款** → **分析扣款**，示範資料裡冷氣在入住時已記錄瑕疵，系統會判斷這筆可主張不扣。
3. 到「＋ 財稅試算」輸入全年租金與補貼，按 **試算**。

## 技術說明

- 純前端靜態網站（HTML／CSS／JavaScript），不需要後端、不需要 API 金鑰，可直接用 GitHub Pages 部署。
- **Demo 版以規則比對模擬 AI 判斷**：`rules.js` 是法規知識庫（`LAW`）與檢查規則（`RULES`）。
- 資料只存在使用者瀏覽器的 localStorage，不會上傳；照片只在本次瀏覽時預覽，不會被儲存。

### 完整版架構（企劃書規劃）

```
輸入：契約照片、點交與退租照片、扣款明細、財稅資料
  ↓
AI 處理層：OCR 文字辨識 → RAG 法規檢索 → LLM 推理與草擬；影像辨識與前後比對
  ↕ 租屋檔案（契約、點交照片與時間戳）      ↑ 法規知識庫（應記載／不得記載事項、契約範本、民法、所得稅法）
  ↓
輸出：契約紅綠燈報告、點交清單、押金行動包、財稅試算結果
```

接上真正的 AI 時，可以把 `analyzeContract()` 換成呼叫 LLM（例如 AWS PartyRock 或 Amazon Bedrock），並把 `LAW` 當成 RAG 的檢索來源，規定每個結論都要附條文出處，找不到依據就回答「無法判斷」。

## 檔案結構

```
rentguard-demo/
├── index.html   # 頁面與四個功能分頁
├── style.css    # 視覺樣式（深綠 × 暖灰，與簡報主視覺一致）
├── rules.js     # 法規知識庫、契約檢查規則、財稅試算
├── app.js       # 介面互動、點交存證、押金分析
├── .nojekyll    # 讓 GitHub Pages 直接提供檔案
└── README.md
```

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `rentguard-demo`，設為 Public。
2. 把這個資料夾的所有檔案上傳到 repository 根目錄（網頁上按 **Add file → Upload files**，或用 git push）。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1～2 分鐘，網址會出現在同一頁：`https://<帳號>.github.io/rentguard-demo/`。把它填進企劃書的「原型連結」。

用指令上傳的話：

```bash
cd rentguard-demo
git init
git add .
git commit -m "RentGuard demo"
git branch -M main
git remote add origin https://github.com/<帳號>/rentguard-demo.git
git push -u origin main
```

## 法規依據

| 主題 | 重點 | 來源 |
| --- | --- | --- |
| 押金上限 | 押金最高不得超過二個月租金總額 | [住宅租賃契約範本](https://osa.nycu.edu.tw/menuDoc/20293) |
| 租期內漲租 | 出租人於租賃期間不得藉任何理由要求調漲租金 | [住宅租賃契約範本](https://osa.nycu.edu.tw/menuDoc/20293) |
| 租金補貼 | 契約不得禁止或以不當條款限制承租人申請租金補貼 | [內政部修正說明](https://www.ssivs.chc.edu.tw/resource/openfid.php?id=10514) |
| 提前終止 | 應至少一個月前通知；未通知者違約金最高一個月租金 | [住宅租賃契約範本](https://lawinsider.com/zh/contracts/hKgvnRdYnUf) |
| 電費 | 2024/7/15 起新約按度數計費，每度不得超過電費單當期每度平均電價 | [新頭殼報導](https://newtalk.tw/news/view/2024-07-15/928046) |
| 租金特別扣除額 | 113 年度起每戶每年上限 18 萬元，需先減除政府補貼；有屋者原則不適用，另有例外與排富條款 | [聯合新聞網](https://udn.com/news/story/7243/9471349) |

**待查證**：房東進入租屋處的通知要求、合理耗損的認定方式、各縣市租賃爭議調處流程。正式版將以內政部公告、全國法規資料庫與財政部原文為準。
